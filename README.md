# WorldWise - Travel Tracker App

WorldWise is a React-based web application designed to help you keep track of your travel adventures. With an interactive map and detailed city information, you can log your trips, add notes, and visualize your journey across the globe.

## Features

- **Interactive Map**: View your visited cities on a dynamic map.
- **City Management**: Add, view, and delete cities from your travel list.
- **Notes**: Attach personal notes to each city to remember your experiences.
- **Date Tracking**: Record the dates of your visits for a detailed travel history.

## Technologies Used

- **React**: For building the user interface.
- **Vite**: For fast development and build processes.
- **React Router**: For seamless navigation between pages.
- **Leaflet**: For the interactive map functionality.
- **LocalStorage**: To persist user data locally.
